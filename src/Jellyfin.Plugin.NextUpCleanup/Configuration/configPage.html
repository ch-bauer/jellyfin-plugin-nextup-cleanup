Next Up Cleanup

Since 10.11 the Next Up row also holds the first episode of every series you never started. This filters those entries out of the server's response, on every client. No watch data is changed — switch the plugin off and the row is back to normal.

When off, the plugin is a pass-through and no response is touched.
Every first episode removes all S01E01 entries, without exception. This is the one that empties the row.

Only untouched is narrower: it keeps any S01E01 you have ever touched, meaning it has a resume position, a play count, a played flag or a played date — so an episode you started once and abandoned, or finished and are being offered again, stays in the row. Only entries with none of those four are removed.

Either way, on a row that also carries Continue Watching, an episode with a resume position is never removed — you never lose the thing you are part-way through.
The server applies the client's row length before this plugin removes anything, so a 20-item row would come back short. Asking for this many times as many rows keeps it full. 1 disables over-fetching.
Upper bound on the inflated row length, so a client asking for a long row cannot turn into a very expensive query.
