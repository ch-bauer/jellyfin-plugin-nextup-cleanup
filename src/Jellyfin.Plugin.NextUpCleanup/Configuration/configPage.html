Next Up Cleanup

Since 10.11 the Next Up row also holds the first episode of every series you never started. This filters those entries out of the server's response, on every client. Filtering changes no watch data — switch the plugin off and the rows are back to normal. The only thing that writes anything is the opt-in task at the bottom of this page.

When off, the plugin is a pass-through and no response is touched.
Every first episode removes all S01E01 entries, without exception. This is the one that empties the row.

Only untouched is narrower: it keeps an S01E01 you have actually watched — one that is marked played, or that you got past the “started watching” mark below in. Everything else goes.

Either way, on a row that also carries Continue Watching, an episode you are genuinely part-way through is never removed.
Jellyfin writes a resume position, a play count and a play date the moment playback starts, so a mis-tap or a look at the opening titles is enough to pin an episode to the row for good. Per-series toggle

Adds an eye button next to Play on a series page. Switching a series off removes every one of its episodes from Next Up and Continue Watching, with no exceptions — episode number, play state and the marks above stop applying to it. Each user has their own list, so switching a series off does not affect anybody else. Turning this off only hides the button; series already switched off stay switched off.

Abandoned episodes

Filtering already keeps barely-started episodes out of every row. This is for tidying up what sits behind them, in Dashboard → Scheduled Tasks → Reset abandoned episodes. That task deletes watch data and cannot be undone, so it never runs on its own — you have to start it by hand.

The task clears the resume position, play count and play date of any episode stopped before this mark. Episodes marked played are never touched. Keep this well below the “started watching” mark.
